Choose your AI provider

Free and private: the model runs on your computer's graphics chip and nothing you write leaves this browser. The first download takes a few minutes and is kept for next time. Writing is slower than ChatGPT or Claude and the quality is simpler, so review drafts carefully. It can't search the web, so fact-checking and AI-answer checks need an API provider.

Set up Ollama (one time, about 10 minutes)
  1. 1Download and install the free app from ollama.com.
  2. 2Open Terminal and download a model: ollama pull qwen3:8b (about 5 GB; good for 16 GB Macs). For more powerful computers: ollama pull qwen3:14b.
  3. 3Allow this website to use it. On a Mac run then quit and reopen the Ollama app.
  4. 4Click Load models above, choose your model, then Save and Test connection. Chrome may ask to allow access to apps on your computer: choose Allow.

Free and private, and usually better than the built-in AI because it can run bigger models. It can't search the web, so fact-checking and AI-answer checks need an API provider.

Your key is stored only in this browser and sent directly to the provider. Don't save keys on shared computers: untick "Remember" and the key is forgotten when you close the tab. Usage is billed to your own account.

Weekly monitoring optional

Once a week, even with no browser open: checks your key pages (errors, noindex, title changes, redirects), compares Google clicks with the week before, notes new Google updates, and lists pages waiting for approval and overdue to-dos. Then it emails a short summary.

Leave all websites unticked to check every website. If a week is missed, the check runs at the next opportunity.

Chat alerts Slack, Teams, Google Chat

Send the weekly summary, urgent problems, reviews, sign-offs and @mentions to your team's chat.

Hybrid mode: free writing, paid review optional

Your free AI (Built-in AI or Ollama) writes the page; a paid model plans it, reviews quality, fixes the flagged sections and fact-checks with its own web search. Paid models charge most for writing, so this typically saves 30–60% compared with writing everything with the paid model: less when many review rounds are needed, more for long pages. Each page's report shows its estimated saving. Choosing a smaller paid model for review (for example Claude Haiku or a GPT mini model) saves more.

Free search engine tools optional

A free Google API key unlocks page speed tests (Site health → Speed) with Google's full free allowance of about 25,000 tests a day. A free Bing key adds Bing data (Google search screen).

How to get the key (5 minutes, free, no billing)
  1. 1Go to console.cloud.google.com and choose or create a project (the same one as for Search Console is fine).
  2. 2APIs & Services → Library: enable PageSpeed Insights API and Chrome UX Report API (the second powers the quick real-visitor check).
  3. 3APIs & Services → Credentials → Create credentials → API key. Then Edit the key: under API restrictions choose only PageSpeed Insights API and Chrome UX Report API, and under Application restrictions choose Websites and add your site's address.
  4. 4Paste the key below and click Save.

Bing Webmaster Tools

In Bing Webmaster Tools (free; add your site there, or import it from Google Search Console in one click), open Settings → API access → API key, generate a key and paste it here. It stays in this browser.

Web search for the free AI options optional

Built-in AI and Ollama can't search the web by themselves. Add a free search key and the tool searches for them, so they can research what ranks and fact-check pages.

Results are cached for a day so repeated checks don't use up searches. A page fact-check uses about 6 searches; a keyword check uses 1.

Team workspace optional

Share websites, keywords, pages, plans and to-dos with your team, and keep a cloud backup. Everyone who enters the team password sees the same data. API keys are never shared.

How to set it up (one time, for whoever manages the Netlify site)
  1. 1In Netlify, open your site → Site configuration → Environment variables → Add a variable. Name: TEAM_PASSWORD, value: a long password.
  2. 2Go to Deploys → Trigger deploy so the change takes effect.
  3. 3Share the password with your team. Each person enters it here and clicks Turn on team sync.

Data is stored in Netlify Blobs, part of your Netlify site. Changes sync every 2 minutes and a few seconds after you edit. When two people change the same list (for example keywords), both sets of changes are kept; when two people edit the same item at once, the latest save wins.
